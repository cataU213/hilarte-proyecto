## 📝 Descripción

HilArte es una página web orientada a la presentación de productos artesanales, como artículos de crochet, sábanas y regalos personalizados.

El proyecto incluye una página principal, un catálogo de productos, tablas informativas y formularios de contacto.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Diseño responsive

## ✨ Funcionalidades

- Navegación entre secciones
- Catálogo de productos
- Tarjetas con imágenes y precios
- Tabla de productos
- Formularios de contacto
- Adaptación a dispositivos móviles

## 🎯 Objetivo del proyecto

Aplicar conocimientos de estructura HTML, estilos CSS, diseño responsive y organización visual de una página web.
